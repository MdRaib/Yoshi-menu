# Yoshi — Premium Restaurant Digital Menu

A polished standalone restaurant menu based on the supplied final design.

## Brand
- Brand name: **Yoshi**
- Style: premium Chinese & Thai restaurant
- Logo: `assets/logo.svg`

## Features
- Responsive premium menu
- Category filtering
- Add-to-order cart
- Quantity controls
- Table number checkout
- WhatsApp table ordering
- Easy editing through `site-config.js`

## Edit menu
Open `site-config.js` and change each product's:
- `name`
- `category`
- `price`
- `image`
- `desc`
- `badge`

Change the WhatsApp number in:
`WHATSAPP: "+8801XXXXXXXXX"`

## Hosting
Upload the folder to GitHub Pages, Netlify, Vercel, or regular static hosting.
